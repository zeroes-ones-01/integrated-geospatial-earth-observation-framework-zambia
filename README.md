# Zambia Agricultural Emissions SQL System

## Project Overview
This project builds a relational database system to analyse agricultural inputs, emissions, land-use change, and environmental sustainability in Zambia.

## Objectives
- Analyse fertilizer use vs crop yield
- Study emissions (N2O, CO2, CH4)
- Evaluate land-use change and deforestation
- Assess climate impact on agriculture

## Tools Used
- SQL (PostgreSQL)
- QGIS
- World Bank datasets

## Data Structure
- Province-year panel dataset
- Agricultural inputs
- Emissions data
- Climate data

## Key Research Question
How do input-dependent agricultural practices affect environmental sustainability in Zambia?

# zambia-agri-emissions-sql
This project builds a relational SQL database for analysing input-dependent agriculture in Zambia. It integrates fertilizer use, yields, land-use change, climate data, and N₂O, CO₂, and CH₄ emissions in a province-year structure, enabling spatial and temporal assessment of sustainability using World Bank data.
